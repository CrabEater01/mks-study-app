MSK Anatomy Quiz
================
Open index.html in Chrome, Safari or Firefox (double-click it). No internet needed.

Quiz       Name the structure at the pink arrow and press Enter.
           Close misspellings: you choose pass or fail.
           Another real term: shows you that term's image so you can compare.
Arrow review (optional)  Drag or rotate any arrow that looks off, or mark it wrong. Skip it if you like.
Browse     Every term by section. "Only terms with no image" lists the ones still missing a picture.
Settings   1/2/3 correct answers per term, sections on/off or Focus, removed terms, backup export/import.

Progress saves in this browser automatically. Use Settings > Export backup to move it elsewhere.
Images: Gray's Anatomy (1918, public domain) via Wikimedia Commons, plus one CC BY 3.0 breast diagram.
Labels were removed digitally; "Show labeled plate" shows the original.
